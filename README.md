# Change Website Font
This is a browser extension that will change the font on a website to what you select.

## Branding assets
To keep icons sharp in Chrome and Firefox, design a square master logo (at least 1024×1024), then export:

- `icons/icon16.png` (toolbar)
- `icons/icon48.png` (extension management page)
- `icons/icon128.png` (store/listing usage)

Tip: keep the icon simple (high contrast initials like `Aa`), centered, with generous padding so it stays readable at 16×16.
